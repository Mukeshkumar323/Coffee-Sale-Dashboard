# Task 2: Data Visualization and Storytelling

## Project Title
Coffee Shop Sales Dashboard

## Objective
To analyze coffee shop sales data using Power BI and create an interactive dashboard that provides meaningful business insights.

## Description
This project analyzes coffee shop sales data using Power BI. The dashboard displays total sales, total orders, coffee type performance, payment methods, customer spending, and city-wise sales. It helps identify business trends and supports better decision-making.

## Tools Used
- Power BI
- Microsoft Excel/CSV Dataset

## Dataset
- Coffee Shop Sales Dataset

## Data Cleaning Process
1. Imported the dataset into Power BI.
2. Checked for missing (null) values.
3. Removed duplicate records.
4. Removed extra spaces from text fields.
5. Corrected inconsistent product and city names.
6. Changed data types (Text, Number, Date).
7. Verified sales, quantity, and price values.
8. Removed unnecessary columns.
9. Created required measures using DAX.
10. Loaded the cleaned data for visualization.

## Dashboard Features
- KPI Cards (Sales, Orders, Items Sold)
- Coffee Type Analysis
- City-wise Sales
- Payment Method Analysis
- Customer Spending Analysis
- Interactive Filters

## Storytelling / Key Insights
1. Total sales amount is 49K.
2. The coffee shop received 100 orders.
3. A total of 257 items were sold.
4. Cappuccino is the highest-selling coffee type.
5. Espresso has the lowest sales.
6. Cash is the most preferred payment method.
7. Sales are generated from Bangalore, Chennai, Delhi, Hyderabad, Mumbai, and Pune.
8. Promotions can improve sales of low-performing coffee products.
9. The dashboard helps monitor sales performance and customer behavior.
10. The insights support better business decisions.
